## 🛡️ **SOC Home Lab — meu principal projeto**

Ambiente de SOC montado do zero: Kali (atacante) → Windows 10 + Ubuntu (alvos) → Wazuh (SIEM) centralizando a detecção.

Para cada ataque: executo → detecto no SIEM → investigo → mapeio ao MITRE ATT&CK → documento.

🔍 Detecção via SIEM (Wazuh) — correlação de logs e regras customizadas 🧭 Mapeamento de ataques ao MITRE ATT&CK (brute force, reconhecimento, PowerShell ofuscado) 🚨 Investigação e resposta a incidentes com relatórios em formato profissional 🖥️ Análise de telemetria em Windows (Sysmon) e Linux
